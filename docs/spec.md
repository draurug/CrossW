# CrossW — техническое задание

Статус: рабочая версия, 2026-09-10. Устройство кода — в [architecture.md](architecture.md).

## 1. Идея

**Тематичность — свойство определения, а не слова.**

ТРАМВАЙ — обычное слово. «Транспорт, обезглавивший Берлиоза» делает его частью
«Мастера и Маргариты».

Без этого приёма тема невозможна: сетку нечем заполнить, если брать только имена
собственные — коротких тематических слов почти не бывает, а в сетке таких слотов
больше половины.

Три вида записей в контенте:

| `origin` | Пример | Роль |
|---|---|---|
| `topic` | ВОЛАНД → «Профессор чёрной магии» | держит тему, узнаётся сразу |
| `dict` | МАСЛО → «Что разлила Аннушка» | даёт короткие слова и основную массу тематичности |
| `filler` | ОКНО → «Проём в стене» | замыкает сетку там, где темы не хватило |

## 2. Пользователь

Человек за компьютером, который любит книги и устал от определений вроде «столица
Франции». Ему нужно: решать с клавиатуры, видеть источник спорного факта, вернуться
завтра к недорешённой сетке.

**Мобильной версии нет намеренно.** Сетка 15×15 и полсотни определений на телефоне
превращаются в прокрутку. Вёрстка не адаптивная и не притворяется.

## 3. Что входит в первую версию

| Блок | Готово, когда |
|---|---|
| Классический кроссворд, сквозная нумерация, определения справа | номер в клетке и в списке всегда совпадают |
| Клавиатурный ввод: буквы, стрелки, Backspace, Tab, Пробел | кроссворд решается без касания мыши |
| Проверка буквы, слова, всего; подсказка; счётчики | проверка не стирает верные буквы |
| Таймер и прогресс в `localStorage` | после перезагрузки те же буквы, время и счётчики |
| Каталог тем, карточки кроссвордов | с главной любой кроссворд за два клика |
| Страница «Источники» | ссылка на неё есть в подвале |
| Генератор сеток `npm run gen` | сгенерированное проходит `npm run validate` без правок |
| Контент | 9 кроссвордов по 3 темам, каждый прошёл валидатор и ручное решение |

## 4. Что намеренно не входит

| Не делаем | Почему |
|---|---|
| Сканворды со стрелками | другая механика ввода, вёрстка и генератор — это второй продукт |
| Мобильная версия | см. §2 |
| Симметричные сетки американского типа | требуют словаря филлеров; на паке из 200 слов недостижимы |
| Английские кроссворды | нужны свой словарь и носительский язык; `lang` в типах есть, контента нет |
| Аккаунты, рейтинг | требуют сервера; сайт статический, и это его главное свойство |
| Ежедневный кроссворд | при ручном контенте обещание невыполнимо |
| Редактор сеток в браузере | автору хватает JSON и валидатора |

## 5. Критерии приёмки

1. Кроссворд решается целиком с клавиатуры, ни разу не коснувшись мыши.
2. После перезагрузки те же буквы, то же время, те же счётчики.
3. Переизданный с другими ответами кроссворд не подхватывает старый прогресс:
   ключ в `localStorage` содержит хэш решения.
4. Введённая Ё засчитывается как Е; в сохранённых ответах Ё нет вообще.
5. Проверка «всё» помечает неверные, но не стирает верные и не открывает ответы.
6. Номера в клетках и в списке совпадают; в JSON кроссворда нет номеров, записанных руками.
7. `npm run validate` падает при: отсутствии определения, однокоренном определении,
   тематическом определении без источника, слове короче трёх букв, изолированной клетке,
   дубле ответа. Слишком длинное определение — предупреждение: лимит калибруется по вёрстке.
8. `npm run validate` падает, если тематических подсказок меньше 60%.
9. В `public/p/<id>.json` нет ни одной буквы ответа.
10. `npm run build` проходит на чистом клоне: `public/p/` собирается из `content/`.

## 6. Правила определений

Сетку можно перерисовать за час, плохое определение убивает кроссворд насовсем.

1. **2–4 слова, до 40 символов.** *(валидатор)* Определение читается боковым зрением.
   «Транспорт, обезглавивший Берлиоза», а не «Транспорт, под колёсами которого погиб Берлиоз».
2. **Никаких однокоренных с ответом.** *(валидатор)* МАСЛО → «Что разлила Аннушка»,
   а не «Масло, которое разлила Аннушка».
3. **Не синоним, а функция, признак или контекст.** ПРИМУС → «Что починял кот Бегемот»,
   а не «Нагревательный прибор».
4. **Однозначность внутри темы.** ВОЛАНД → «Профессор чёрной магии»,
   а не «Иностранец в Москве» — под это подходит вся свита.
5. **Факт, а не пересказ.** БЕЗДОМНЫЙ → «Поэт из МАССОЛИТа»,
   а не «Герой, который меняется по ходу романа».
6. **Без спойлеров развязки в лёгких кроссвордах.** События первых глав не спойлер.
   Спойлерное определение помечается `difficulty: "hard"` и в лёгкие не попадает.
7. **Безопасно для детей.** Из книги берутся факты, а не натурализм.
8. **У тематического определения обязателен `source`.** *(валидатор)* «МиМ, гл. 3»,
   «Собака Баскервилей». Словарному определению источник не нужен.

Машина проверяет пункты 1, 2, 8 и дубли. Пункты 3–7 — на ревью автором.

## 7. Ё и алфавит

Ё сводится к Е везде: в ответах пака, в сетке при компиляции, при вводе с клавиатуры.
Так в бумажных кроссвордах, и заодно закрывается класс багов «ввёл Е, а в ответе Ё».

Алфавит ответов — 32 буквы (А–Я без Ё), только заглавные. Дефисы, пробелы и апострофы
запрещены: слово занимает клетки подряд.

кладётся производное представление, а ссылка на источник обязательна всё равно.
