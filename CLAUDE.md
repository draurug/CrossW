# CrossW — конвенции проекта

Сайт классических кроссвордов под ПК. Главная идея: **тематичность — свойство определения,
а не слова**. ТРАМВАЙ — обычное слово, но «Транспорт, обезглавивший Берлиоза» делает его
частью «Мастера и Маргариты». Подробности — в [docs/spec.md](docs/spec.md), устройство —
в [docs/architecture.md](docs/architecture.md).

## Команды

```bash
npm run dev        # разработка
npm test           # vitest: ядро и движок
npm run validate   # проверка контента: гейт, ошибки и предупреждения
npm run review     # что стоит посмотреть глазами: догадки, не ошибки
npm run refresh    # gen → content → validate одной командой
npm run content    # content/ → public/p/  (входит в build)
npm run build      # статический экспорт в out/
npm run typecheck  # tsc --noEmit
```

## Три правила архитектуры

Нарушение любого из них — повод переписать, а не «поправить потом».

1. **В компонентах нет игровой логики.** Компонент рендерит `PlayState` и зовёт функцию
   движка. Нужно узнать, каким словам принадлежит клетка — спроси индекс, не ищи `.find()`
   по определениям. Предыдущий прототип нарушал это в каждом обработчике и кончил
   компонентом на 346 строк.
2. **Зависимости идут в одну сторону:** `components/` → `engine/` → `core/`. В `core/`
   и `engine/` не может быть ни одного импорта React, DOM, Next или `node:fs`. Работа
   с файловой системой живёт только в `tools/`.
3. **Нумерация вычисляется, а не хранится.** Сквозная нумерация клеток — функция от сетки
   (`core/grid.ts`). В прототипе номера лежали в JSON руками, и существовало два разных
   слова №1 — по горизонтали и по вертикали.

## Данные

Два формата, не путать:

- **source** — `content/puzzles/<id>.json`, лежит в git, сетка с настоящими буквами, чтобы
  её было видно в диффе и можно было проверить глазами. Это то, что ревьюит человек.
- **compiled** — `public/p/<id>.json`, артефакт сборки, в git не хранится. Плоские индексы
  клеток, ни одной буквы ответа. Решение — отдельным файлом `<id>.sol`, где строка ответов перемешана
  по ключу и глазами не читается.

Клетка на пересечении — **один плоский индекс** в `cells` обоих слов. Поэтому расхождение
букв между пересекающимися словами невозможно в принципе; сверять их не надо.

## Русский язык в кроссвордах

Ё всегда сводится к Е — и в ответах, и при вводе с клавиатуры. Традиция кроссвордов,
заодно снимает класс багов «ввёл Е, а в ответе Ё». Ответы хранятся заглавными.

## Стиль

- Комментарии, тексты ошибок и описания тестов — по-русски. Код и имена — по-английски.
- Все видимые пользователю строки живут в `src/i18n/ru.ts`, не в JSX.
- Цвета — через CSS-переменные в `globals.css` и токены Tailwind (`bg-cell-active`),
  не хардкодом в компонентах: тёмная тема переопределяет их одним местом.
- `noUncheckedIndexedAccess` включён: `arr[i]` имеет тип `T | undefined`.

## Чего в проекте сознательно нет

Монорепо с отдельными пакетами · zod · CI · Playwright · Lighthouse. При одном разработчике
и пяти кроссвордах это обвязка ради обвязки. Чистота архитектуры здесь стоит ноль строк —
она в направлении зависимостей, а не в числе файлов `package.json`.
