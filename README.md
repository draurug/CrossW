# CrossW

Сайт классических кроссвордов под ПК, где определения привязаны к книгам.

Главная идея: **тематичность — свойство определения, а не слова.** ТРАМВАЙ —
обычное слово, но «Транспорт, обезглавивший Берлиоза» делает его частью
«Мастера и Маргариты». Без этого приёма тему нечем наполнить: коротких
тематических слов почти не бывает, а в сетке таких слотов больше половины.

Живой сайт: <https://crossw.draugur3-14.workers.dev>

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
```

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | разработка |
| `npm test` | 75 тестов: ядро и движок |
| `npm run validate` | гейт контента: ошибки и предупреждения |
| `npm run review` | что стоит посмотреть глазами — догадки, не ошибки |
| `npm run gen` | собрать сетки из паков |
| `npm run content` | `content/` → `public/p/` |
| `npm run build` | статический экспорт в `out/` |
| `npm run deploy` | сборка и выкладка на Cloudflare |

## Что где лежит

1. `src/core/` — сетка, типы, нумерация, правила. Чистые функции.
2. `src/engine/` — состояние игры. Тоже чистые функции, без React.
3. `src/components/`, `src/hooks/` — интерфейс. Вся логика игры зовётся из движка.
4. `content/packs/` — словари тем: слова с определениями. Это ревьюит человек.
5. `content/puzzles/` — сетки с настоящими буквами, в гите, видны в диффе.
6. `public/p/` — то, что получает браузер: ни одной буквы ответа. Артефакт сборки.
7. `tools/` — генератор, компилятор контента, валидатор. Только здесь есть `node:fs`.
8. `content/sources/` — тексты книг. **В гит не попадают**, каталог в `.gitignore`.

## Два формата данных

**source** (`content/puzzles/<id>.json`) — сетка буквами, человекочитаемая, в гите.
**compiled** (`public/p/<id>.json`) — плоские индексы клеток, без ответов. Решение
уходит отдельным файлом `<id>.sol`, где строка ответов перемешана по ключу
и глазами не читается. Это защита от «посмотреть исходник», не криптография.

## Как добавить тему

Нужны три файла, одного пака мало:

1. `content/packs/<тема>.json` — 150–200 слов с определениями;
2. запись темы в `content/topics.json`;
3. три названия кроссвордов в `TITLES` в `tools/gen.ts`.

Пак пишется не руками: в `.claude/agents/` лежат `pack-writer` и `pack-editor`,
правила — в `.claude/skills/write-pack/SKILL.md`. Дальше `npm run gen`
и `npm run refresh`.

Имена файлов и slug — настоящие английские названия, не транслитерация:
`twelve-chairs`, а не `dvenadtsat-stulyev`.
